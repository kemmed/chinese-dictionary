# 🀄 Chinese Dictionary (Китайский Словарь)

> **О проекте:** Это легкое веб-приложение для изучения китайского языка, созданное исключительно для личного использования. 
>
> ⚠️ **Важно:** Весь код этого проекта был написан нейросетью **Qwen**.

🔗 **[Открыть приложение (GitHub Pages)](https://kemmed.github.io/chinese-dictionary/)**

> ‼️**ВНИМАНИЕ‼️:**   
> Прогресс обучения (изученные слова и отметки о повторении) сохраняется **ТОЛЬКО ЛОКАЛЬНО** в браузере вашего устройства (через `localStorage`). 
> *   Данные **не синхронизируются** между разными устройствами (например, если вы учили слова на телефоне, на компьютере они не появятся).
> *   При очистке истории браузера или кэша прогресс может быть потерян.

## ✨ Возможности и функционал

Приложение предлагает комплексный подход к запоминанию иероглифов без необходимости установки дополнительных программ:

*   📋 **4 режима обучения:**
    *   **Список слов:** Удобный просмотр всех слов с карточками.
    *   **🎴 Карточки:** Режим флеш-карточек для самопроверки.
    *   **✍️ Диктант:** Проверка знаний по пиньиню, переводу или обоим сразу.
    *   **🎯 Тест:** Режим множественного выбора (перевод/пиньинь → иероглиф).
*   🔁 **Умная система повторений:** 
    *   Возможность отметить изученное слово как "Нужно повторить".
    *   Отдельный фильтр **"🔁 Надо повторить"** позволяет запускать диктант или тест строго по сложным словам.
*   🔍 **Гибкая фильтрация:** 
    *   По учебникам, частям и конкретным урокам.
    *   По тематическим категориям (местоимения, глаголы и т.д.).
    *   Полнотекстовый поиск по иероглифам, пиньиню или переводу.
*   💾 **Автосохранение:** Весь прогресс (изученные слова и слова на повторение) сохраняется в `localStorage` браузера.
*   📱 **Адаптивный дизайн:** Корректно работает на ПК и мобильных устройствах.

## 📚 Структура данных

Словарная база разделена на три отдельных файла для удобства обновления:
1.  `book-textbook.js` — слова из основного учебника.
2.  `book-listening.js` — слова из книги по аудированию.
3.  `book-workbook.js` — слова из рабочей тетради.

## ➕ Как добавить новые слова

Чтобы добавить новые слова, откройте соответствующий `.js` файл и добавьте новый объект в массив (`words`, `wordsListening` или `wordsWorkbook`). 

### 📝 Формат записи слова:
Каждое слово описывается объектом со следующими полями:

```javascript
{
  id: 7,                          // Уникальный номер слова (число)
  hanzi: "八",                    // Иероглиф(ы) (строка)
  pinyin: "bā",                   // Пиньинь с тонами (строка)
  translation: "восемь",          // Перевод на русский язык (строка)
  book: 1,                        // Номер учебника: 1 (Основной), 2 (Аудирование), 3 (Раб. тетрадь)
  part: 1,                        // Номер части учебника (обычно 1 или 2)
  lesson: 1,                      // Номер урока (число)
  category: "числа"               // Тематическая или грамматическая категория (строка)
}

### 💡 Пример добавления блока слов:
```javascript
cconst words = [
  // === УЧЕБНИК 1 ===
  // Урок 1.1
  {id: 1, hanzi: "你", pinyin: "nǐ", translation: "ты, вы (ед.ч.)", book: 1, part: 1, lesson: 1, category: "местоимения"},
  {id: 2, hanzi: "好", pinyin: "hǎo", translation: "хороший; хорошо", book: 1, part: 1, lesson: 1, category: "прилагательные"},
  
  // Урок 1.2
  {id: 7, hanzi: "八", pinyin: "bā", translation: "восемь", book: 1, part: 1, lesson: 2, category: "числа"},
  // ... добавляйте новые строки по аналогии
];
```

> **Важно:** Не забудьте поставить запятую `,` после каждого объекта, кроме последнего в массиве. После добавления слов просто обновите страницу в браузере.

## 🚀 Как запустить

Есть два удобных способа использования приложения:

### 🌐 Способ 1: Онлайн (Рекомендуемый)
Просто откройте приложение прямо в браузере по ссылке на GitHub Pages. Ничего скачивать и устанавливать не нужно, прогресс будет сохраняться в вашем браузере:
🔗 **[Открыть приложение онлайн](https://kemmed.github.io/chinese-dictionary/)**

### 💻 Способ 2: Локально (Скачивание)
Если вы хотите использовать приложение офлайн или планируете редактировать код и добавлять свои слова:
1. Скачайте или склонируйте этот репозиторий на свой компьютер.
2. Убедитесь, что в папке находятся все необходимые файлы: `index.html`, `book-textbook.js`, `book-listening.js`, `book-workbook.js`.
3. Просто дважды кликните по файлу `index.html`, чтобы открыть его в любом современном браузере (Chrome, Safari, Firefox и т.д.).
4. Установка локального сервера или дополнительных зависимостей **не требуется**.
